# Rapport — TD1 

## Points clés

### 1. Le découpage d'un site web

Pendant la séance on a découpé un site web en différentes parties pour mieux comprendre comment il est construit, cela
permet d’organiser le html de manière lisible avec les bonnes balises.

### 2. Le rôle du html

Le HTML permet de créer la structure d’un site web. Il permet d’ajouter du texte, des images et des titres pour construire 
la page.

### 3. La différence entre le html et le css

Le HTML permet de structurer le contenu d'un site comme par exemple créer un titre, alors que le CSS sert à mettre en 
forme le site, en changeant la couleur du titre, la taille ou la position...

# Rapport — TD3

## Points clés

### 1. Modèle événement → état → rendu

Le modèle événement → état → rendu décrit comment une page Web réagit aux actions de l’utilisateur. Au début, un événement se produit comme par exemple un clic. Ensuite, cela modifie un état par exemple un menu ouvert et à la fin le rendu change, ça affiche quelque chose de nouveau.


### 2. ClassList.toggle

classList.toggle c'est un outil qui permet de changer l’apparence d’un élément avec une classe CSS, sans toucher directement au
style dans le java script.

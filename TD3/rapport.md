# Rapport — TD3

## Points clés

### 1. Modèle événement → état → rendu

Le modèle événement → état → rendu décrit comment une page Web réagit aux actions de l’utilisateur. D’abord, un événement se 
produit (clic, touche, scroll…). Ensuite, cela modifie un état interne (par exemple un menu ouvert ou un compteur incrémenté).
Enfin, le rendu change : l’affichage à l’écran reflète le nouvel état.

### 2. ClassList.toggle

classList.toggle est un outil qui permet de changer l’apparence d’un élément via une classe CSS, sans toucher directement au
style dans le java script.
